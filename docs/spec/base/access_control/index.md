#### インデックス閲覧可否

- 閲覧可の場合
    インデックスに登録されておりユーザに閲覧権限があるアイテムが表示されます。  
    アイテムの閲覧権限は後述します。  

- 閲覧不可の場合
    `権限が必要です`と表示されます。

| ロール \ インデックス  |   親インデックス: 閲覧可<br>インデックス: 公開  | 親インデックス: 閲覧可 <br> インデックス: 非公開  | 親インデックス: 閲覧不可 |
| --------------------  | -----------  | ------------ |------------ |
| System Administrator<br>Repository Administrator    |  ◯ |  ◯ |   ◯   |
|  非管理者、閲覧権限: 権限あり   |  ◯  |  ✕ |  ✕  |
|  非管理者、閲覧権限: 権限なし   |  ✕  |   ✕  |  ✕ |

非管理者とは、ユーザがSystem Administrator、Repository Administratorのロールを持たないことを指します。  
閲覧権限ありとは、管理画面の`インデックス編集 > 閲覧権限`でユーザの持つロールまたはグループが`権限あり`に設定されている状態を指します。  
インデックス:公開とは、管理画面の`インデックス編集 > 公開`で`公開`にチェックがあり、`公開日`が空または過去の日付に設定されている状態を指します。  
親インデックス:閲覧可とは、親インデックスがRoot Indexである、または上記の判定の結果ユーザが親インデックスを閲覧できる状態を指します。
