### インデックスツリー

エンドポイント: `/search?search_type=2&q=<インデックスID>`

#### インデックス閲覧可否

| ロール \ インデックス  |   親インデックス: 閲覧可<br>インデックス: 公開  | 親インデックス: 閲覧可 <br> インデックス: 非公開  | 親インデックス: 閲覧不可 |
| --------------------  | -----------  | ------------ |------------ |
| System Administrator<br>Repository Administrator    |  ◯ |  ◯ |   ◯   |
|  ロール: 非管理者<br>閲覧権限: 権限あり   |  ◯  |  ✕ |  ✕  |
|  ロール: 非管理者<br>閲覧権限: 権限なし   |  ✕  |   ✕  |  ✕ |

◯: 閲覧可、✕: 閲覧不可

`非管理者`とは、ユーザがSystem Administrator、Repository Administratorのロールを持たないことを指します。  
`閲覧権限あり`とは、管理画面の`インデックス編集 > 閲覧権限`でユーザの持つロールまたはグループが`権限あり`に設定されている状態を指します。  
`インデックス:公開`とは、管理画面の`インデックス編集 > 公開`で`公開`にチェックがあり、`公開日`が空または過去の日付に設定されている状態を指します。  
`親インデックス:閲覧可`とは、親インデックスがRoot Indexである、または上記の判定の結果ユーザが親インデックスを閲覧できる状態を指します。  

- 閲覧可の場合  
    インデックスに登録されておりユーザに閲覧権限があるアイテムが表示されます。  
    アイテムの閲覧権限は後述します。  

- 閲覧不可の場合  
    `権限が必要です`と表示されます。
